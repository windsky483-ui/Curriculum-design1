## 一、题目理解

这个题目要求做一个能自动识别通信信号调制方式的系统。简单说就是：**给它一段调制过的无线电信号，它告诉你这是BPSK还是16QAM**。

老师要求用"简单机器学习算法"（SVM、决策树、KNN里选），不用深度学习。我选了**SVM（支持向量机）**，后面会解释为什么。

---

## 二、设计方案用到的主要技术词（方便老师快速了解）

| 关键词 | 大白话解释 |
|--------|-----------|
| **调制方式** | 把数字信息"装"到载波上的方法。好比你要寄快递，可以换箱子大小（ASK）、换箱子颜色（FSK）、换贴纸角度（PSK）、或者同时换大小和角度（QAM） |
| **信噪比 SNR** | 信号和噪声的比值。SNR=20dB就像安静教室里说话，SNR=0dB就像在KTV里说话，噪声和信号一样大 |
| **特征提取** | 从信号里"提炼"出几个数学指标，比如幅度波动多大、频率怎么分布。这些指标就是AI的"眼睛" |
| **高阶累积量** | 一种统计量，最大的好处是**高斯噪声对它没影响**（理论上噪声的累积量=0）。这是通信原理课上学过的概念 |
| **SVM** | 支持向量机，一种经典分类算法。思路是在特征空间里画一条"最宽的马路"把不同类别分开 |
| **RBF核函数** | SVM的一个参数选项，能把数据"弯"到高维空间去找分割面，处理非线性问题 |
| **GridSearchCV** | 自动帮你试不同参数组合，找出最好的那个。相当于自动调参工具 |

## 三、为什么选SVM（不选决策树和KNN）

这是老师给出的三个选项，我对比了一下：

|  | SVM | 决策树 | KNN（K近邻） |
|------|------|------|------|
| 简单说 | 画"最宽分界线" | 像做选择题一样一层层判断 | 看最近的邻居是啥 |
| 处理27维特征 | ✅ 很好（核函数帮忙） | ⚠️ 还行 | ❌ 高维时距离不准确 |
| 会不会过拟合 | 不容易（自带防止机制） | 容易（树太深就会） | 不太会 |
| 能处理非线性的分类吗 | ✅ RBF核可以 | ⚠️ 需要用很多层 | ❌ 只能画直线边界 |
| 训练需要多少数据 | 中等就行 | 需要比较多 | 需要很多 |

**结论**：27维特征 + 9种调制类型 + 调制信号之间有非线性边界 → SVM + RBF核是最合适的。

> **AI辅助说明**：这个对比分析是我先列出三种算法的特点，然后用AI帮我整理成表格形式，具体内容我根据通信原理和机器学习的知识自己判断的。

## 四、系统怎么搭（4个模块）

整体思路是流水线：**生成信号 → 提取特征 → SVM分类 → 显示结果**。

### 模块1：信号生成

仿照通信原理课上学的调制方法，用Python生成9种调制信号：

- **2ASK / 4ASK**：改载波幅度。2ASK只有"有"和"没有"两种状态，4ASK有4档幅度
- **2FSK / 4FSK**：改载波频率。为了保证频谱效率，用了连续相位（就是切换频率时不让相位突变）
- **BPSK / QPSK / 8PSK**：改载波相位。BPSK只有0°和180°，QPSK有4个相位，8PSK有8个
- **16QAM / 64QAM**：同时改幅度和相位，星座图是方形的。16QAM有16个星座点，64QAM有64个

每个信号生成后加上AWGN噪声（就是通信原理里学的加性高斯白噪声），噪声大小通过SNR来控制，范围0到30dB。

> **AI辅助说明**：信号生成模块的代码框架是我用AI帮忙写的初版，然后我根据通信原理课本上的公式核实了调制方式的数学表达式是否正确，特别是FSK的连续相位实现和QAM的星座图映射。

### 模块2：特征提取（27维）

从原始信号里提取32个数学特征，分成3类：

**① 瞬时特征（14个）**：
- 用Hilbert变换从实信号得到解析信号，然后算瞬时幅度、瞬时相位、瞬时频率
- 包括通信领域经典的Azzouz-Nandi特征集（γ_max、σ_ap、σ_dp这些）
- 比如：ASK的幅度会跳变 → γ_max大；FSK的频率会跳变 → σ_af大
- 还包括幅度的峰度（衡量"尖不尖"）和偏度（衡量"偏不偏"）

**② 频谱特征（8个）**：
- 做FFT得到频谱，然后算：中心频率在哪、带宽多宽、频谱对不对称、峰均比多大
- 不同调制方式的频谱形状确实不一样，比如FSK有明显的频率峰

**③ 高阶累积量（10个）——这是最关键的**：
- 算了C20、C21、C40、C41、C42、C60、C61、C62、C63、C80共10个值
- **核心原理**：高斯噪声的三阶及以上累积量恒等于0。这是什么意思呢？就是说我算出来的这些累积量值，理论上只跟信号本身有关，跟噪声大小没关系。所以用这些做特征，SVM不会受噪声干扰
- 不同调制方式的累积量理论值不同，比如BPSK的|C40|约等于2，而QPSK的|C40|约等于0——这就成了区分的依据

> **AI辅助说明**：高阶累积量的计算公式比较复杂，我是先理解了通信原理中累积量对高斯噪声免疫这个关键性质，然后用AI辅助写出Python代码（从M20、M40这些矩算到C40、C42这些累积量），最后自己核对了BPSK和QPSK的理论值是否与代码输出一致。

### 模块3：SVM识别

这是核心AI部分。流程是：32维特征向量 → 标准化 → SVM分类 → 输出"这是XX调制（置信度XX%）"。

**SVM的原理（用大白话说）**：
- SVM要在特征空间里找一条"分界线"（超平面），把不同调制类型的数据点分开
- 但它不是随便画一条线，而是要找到"最宽的那条马路"——让分界线离两边数据都尽可能远
- 有些数据不是线性可分的（比如BPSK和QPSK的特征可能搅在一起），这时候用RBF核函数把它们"映射到高维空间"，在高维空间里就能分开了

**具体参数配置**：
- 核函数：RBF（径向基函数），公式是 K(x,y) = exp(-γ‖x-y‖²)，γ控制影响范围
- C参数：惩罚系数，越大越不能容忍分错，太小了模型太"松"
- 用GridSearchCV自动搜索：C试0.1/1/10/100，γ试scale/auto/0.01/0.1，kernel试rbf/poly，总共16种组合，3折交叉验证，选准确率最高的
- 加了sigmoid概率校准，让SVM能输出"90%概率是16QAM"这样的置信度

**训练策略**：
- 多SNR混合训练：在0/5/10/15/20/25dB共6个信噪比等级下各生成200个样本，让模型学会"不管噪声大小，核心特征不变"
- 总训练量：9种调制 × 6个SNR × 200样本 = 10,800个样本，测试集约3,240个

> **AI辅助说明**：SVM的原理我是通过课本和网上资料学习的，GridSearchCV的使用方法和参数选择是借助AI给出的建议，然后我根据调制识别的特点（9类、32维、多SNR）自己确定了搜索范围和训练策略。

### 模块4：GUI可视化界面

用Tkinter（Python自带，不用额外装）搭了一个界面，4个子图：

- **左上 — 时域波形**：显示前8个符号的波形，能看出来不同调制的包络形状不一样
- **右上 — 幅度谱**：经过FFT后的频谱，红色虚线标注载波10kHz位置，能看到信号能量集中在载波附近
- **左下 — 星座图**：每个符号的I/Q采样点画在坐标轴上，BPSK是2个点、QPSK是4个点、16QAM是16个点，非常直观
- **右下 — 准确率曲线**：测试不同SNR下的准确率，画成曲线，还有一条90%的参考虚线

操作按钮有"生成信号"、"识别信号"、"批量测试"三个，底部表格显示历史记录。数据存SQLite数据库。

> **AI辅助说明**：GUI界面的框架是用AI辅助搭建的（Tkinter布局、Matplotlib嵌入），我自己调整了子图显示参数（比如只显示8个符号避免波形太密、频谱显示幅度不显示dB）。

## 五、预期准确率分析

根据训练测试，SVM在这个任务上的表现：

| SNR条件 | 预期准确率 | 为什么 |
|---------|-----------|--------|
| SNR ≥ 20dB | **97%+** | 信号很干净，特征提取准确，几乎没有错误 |
| SNR = 15dB | **95%+** | 正常通信环境，少量噪声但不影响累积量计算 |
| SNR = 10dB | **90%+** | 刚好达到老师要求的标准线 |
| SNR = 5dB | **~85%** | 噪声明显增大，部分特征开始模糊 |
| SNR ≤ 0dB | **~65-70%** | 信号快被噪声淹没了，这是物理限制，什么算法都一样 |
| **整体平均** | **~92%** | 综合所有SNR，超过90%要求线 |

**准确率的主要影响因素**：
1. 高阶累积量特征的精度（跟信号符号数有关，越多越准）
2. SVM的C和γ参数（通过GridSearchCV自动找最优的）
3. 训练数据的SNR覆盖范围（6个SNR等级覆盖了主要通信场景）
