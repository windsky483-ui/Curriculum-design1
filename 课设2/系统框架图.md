### 6大模块的具体内容排版（在Visio文本框内）

```
模块一：信号处理模块 (signal_processor.py)
──────────────────────────────────────────
• RadioML 2016.10a 数据集加载 (.pkl解析)
• 调制名映射: PAM4→4ASK, GFSK→2FSK
• I/Q通道 → 复信号 (sig = I + jQ)
• 信号预处理: 功率归一化 + DC去除
• 索引表构建: {(mod, snr): [signals]}
• 对外接口: get_signal / get_batch / get_snr_list

模块二：特征提取模块 (feature_extraction.py)
──────────────────────────────────────────
• Hilbert变换 → 解析信号
• 瞬时幅度/相位/频率特征 (14维)
• FFT → 频谱特征 (8维)
• 高阶累积量: C20/C21/C40/C41/C42 (5维)
• 输出: 27维特征向量
• NaN/Inf → 0 (避免特征污染)

模块三：AI识别模块 (ai_model.py)
──────────────────────────────────────────
★ 核心创新: 方案A — 逐SNR独立训练
• 10个SNR等级 × 独立Linear SVM
• 核函数: kernel='linear'
• 参数: C=10.0 (GridSearchCV搜索)
• 概率校准: CalibratedClassifierCV (sigmoid)
• 超参数搜索: C ∈ {0.1, 1, 10, 100}
• 输出: 4类概率 + 预测标签
• 持久化: per_snr_models.pkl (10个模型)
• 优势: 准确率天然单调递增

模块四：GUI交互模块 (gui_app.py)
──────────────────────────────────────────
• 框架: Tkinter + Matplotlib
• 控制面板: 调制选择/SNR选择/操作按钮
• 4子图: 时域波形 / 幅度谱 / 星座图 / 准确率曲线
• 逐SNR模型匹配: 自动选最近SNR的模型
• 批量测试: 遍历10个SNR，准确率天然↑
• 重新训练: 逐SNR训练全部10个模型

模块五：数据管理模块 (database.py)
──────────────────────────────────────────
• 数据库: SQLite (modulation_recognition.db)
• 信号生成记录表
• 识别结果历史表
• 模型性能指标表
• 持久化存储: per_snr_models.pkl
  (10个模型 + 10个标准化器 + 特征/标签名)

模块六：系统配置模块 (config.py)
──────────────────────────────────────────
• 调制类型: 4ASK, 2FSK, BPSK, 8PSK
• SNR范围: 0~18dB, 2dB步进, 10个等级
• 数据集路径: RML2016.10a_dict.pkl
• 信号参数: FS=100kHz, RS=1kHz, 128采样点
• 累积量阶数: [20, 21, 40, 41, 42]
• 训练参数: SAMPLES=2000, TEST_RATIO=0.3
• 逐SNR模型路径: per_snr_models.pkl
```
