# 课程设计报告结构摘要

## 题目

AI驱动传输图像的无线通信系统

## 摘要

系统采用预训练 DnCNN 网络进行图像去噪预处理，并使用自编码器实现联合信源信道编码，将图像压缩为低维符号向量后通过 AWGN 信道传输，接收端再解码重建图像。通过不同 SNR 条件下的 PSNR、MSE 和信息熵分析系统性能。

## 主要模块

1. 图像采集与加噪
2. DnCNN 图像去噪
3. 自编码器压缩与重建
4. AWGN 信道传输
5. PSNR、MSE、信息熵性能评估
6. SNR 性能曲线绘制

## 课程知识点对应

- 信号与系统：图像信号处理、噪声建模
- 信息论与编码：信息熵、压缩编码、重建误差
- 通信原理：AWGN 信道、SNR、传输质量评价
